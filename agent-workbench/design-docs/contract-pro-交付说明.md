## 二、原型使用说明

### 如何打开

- 直接**双击 `contract-pro.html`**，或在 Chrome / Edge / Firefox 中拖入打开。
- 全部为内联 CSS + 内联 JS + 内联 SVG 图标，**无外部 CDN / 图片 / 字体引用**，政务内网离线环境可直接运行。
- 编码为 UTF-8；页面最小宽度 1280px，建议 1440px 以上桌面分辨率。
- 已适配 `prefers-reduced-motion`（系统开启「减少动画」时自动关闭过渡动画）。

### 推荐体验入口（演示动线）

1. **生成主线**：左侧导航「工作台 → 合同拟制」→ 点「+ 新建合同」走三步向导（选协议类型 → 录合作要素 → 智能匹配生成）→ 在编辑器右侧打开「智能预审」面板处理四维问题卡（采纳/忽略/修订对比）→ 「保存版本」→ 「导出」草案 + 预审报告。
2. **预审主线**：导航「智能预审 → 预审作业与报告 ★」→ 打开任一作业**详情抽屉**（看疑点清单与法规依据链 chain-card）→ 点「生成预审报告」→ 「归档」看作业状态流转；沿途可顺访「预审模型配置」（画布演示）、「法律法规库」（知识图谱点击高亮）、「预审依据管理」（审核入库流转）、「预审项目库」（穿透查询行内展开）。
3. **工具演示**：导航「智能工具 → 预审工具箱」，三个 Tab 依次体验：多模态导入全流程（上传→预处理→字段配置→智能提取）、图片比对（差异红框 + 相似度环）、合同和图价识别。

## 四、已知限制

### 演示级交互清单（按设计如此，非缺陷）

- **画布连线**：预审模型配置的画布节点连线为静态演示，新增组件不自动布线（画布区已标注说明）。
- **穿透深度**：项目库穿透查询为行内展开明细；预审作业疑点「查看依据」跳转法规库为 switchView + toast 级演示（`chainLaw`），未穿透到法规原文行。
- **多模态上传/识别**：工具箱上传、预处理进度、智能提取、图纸识别均为前端动画演示，不解析真实文件。
- **导出**：Word/PDF/Excel 均为导出演示（toast/弹窗），不产出真实文件。
- **AI 匹配**：大模型语义解析以「智能匹配动画 + 大模型标记」演示，无真实模型调用。
- **筛选**：预审依据管理、预审项目库的筛选按钮为 toast 级演示（法规库/作业库筛选为真过滤，行为不一致属已知项）。

### 遗留 P2 项（不阻断交付，详见审查报告 §三）

1. 依据/项目筛选按钮演示级 toast（同上）。
2. 统计图表存在 5 处硬编码亮色（既有视图遗留，非令牌色）。
3. AI 工具管理为表格而非需求建议的卡片式（信息密度更高，留档说明）。
4. 模板库无独立「历史回溯时间线」可视化（由留痕弹窗承担语义，视为达成）。
5. `renderLibTable` 采用猴子补丁注入生效/作废按钮（功能正常但依赖文本匹配，较脆弱）；另 `tbExport` 按钮残留 1 处 ⬇ 文字符号（既有区豁免范围）。
