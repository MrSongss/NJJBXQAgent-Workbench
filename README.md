南京江北新区政务AI智能体大平台 · 使用说明
============================================

【这是什么】
一个政务办公智能体门户原型（纯前端，双击即用，无需安装、无需联网）。
顶部 8 个导航：主页 / 对话 / 智能体 / 任务流 / 知识库 / 生成记录 / 统计报表 / 通用配置。
门户里点任一智能体，可在对话中快速处理，也可进入「完整工作台」使用该智能体的完整流程演示。

【怎么打开】
1. 推荐 Chrome 或 Edge 浏览器。
2. 直接双击「南京江北新区政务AI智能体大平台.html」。
   （建议分辨率 ≥ 1366×768；窗口越宽体验越好）
3. 进入后：
   - 「主页」中间对话框输入需求 → 自动跳到对话页处理（如：帮我生成一份决定决议）。
   - 顶部「智能体」→ 任一卡片「完整工作台 →」→ 加载该智能体完整流程演示。
   - 完整工作台顶部「返回」回门户；「切换」下拉可换其他智能体；「新窗口打开」可单独全屏使用。
